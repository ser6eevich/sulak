# TableFlow — документация для Antigravity

TableFlow — внутренний веб-сервис для управления продажей, производством, складом и доставкой столов и стульев.

## Как использовать

1. Скопируй эту папку в корень проекта под именем `docs`.
2. Передай Antigravity запрос:

> Изучи все Markdown-файлы в папке `/docs` в порядке нумерации. Не начинай писать код до полного изучения. После чтения составь понимание продукта, карту модулей, предварительную ER-схему, зависимости, риски и поэтапный план. Реализуй только тот этап, который будет указан отдельным промптом.

## Порядок работы

- Сначала использовать `19_MASTER_PROMPT.md`.
- Затем запускать по одному файлу этапа из `21_STAGE_01_PROMPT.md` — `30_STAGE_10_PROMPT.md`.
- Каждый этап должен завершаться сборкой, линтером, тестами, миграциями и отчётом.

## Основные документы

- продукт и бизнес-процесс;
- роли и права;
- заказы и клиенты;
- каталог;
- склад;
- производство;
- логистика и водитель;
- финансы;
- уведомления и аналитика;
- база данных;
- интерфейс, безопасность и тестирование;
- отдельные промпты разработки.
