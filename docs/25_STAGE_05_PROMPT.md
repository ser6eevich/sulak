# Этап 5 — производство

Реализуй производственные задания и позиции, автоматическое создание потребности из недостающих товаров, частичную готовность, сроки, приоритет, проблемы, фотографии и передачу на склад.

Передача должна создавать складской приход одной транзакцией и не дублироваться при повторном запросе. Просрочка создаёт внутреннее уведомление и проблемный статус.
