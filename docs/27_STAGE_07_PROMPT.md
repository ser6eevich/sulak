# Этап 7 — кабинет водителя

Создай мобильный кабинет: свои рейсы, текущий рейс, точки, карточка заказа, звонок, Яндекс Карты, 2ГИС, разрешённые статусы, фото, перенос, отказ, повреждение, сумма и способ оплаты.

Водитель не видит чужие данные. Переходы статусов валидируются на сервере. Недоставленный товар остаётся на локации автомобиля до подтверждённого возврата.
