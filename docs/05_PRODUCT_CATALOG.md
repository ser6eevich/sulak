# Каталог товаров

## Категории

Столешницы, ножки, стулья, крепёж, упаковка, готовые комплекты, дополнительные товары и услуги.

## Товар

Название, категория, описание, базовый SKU, единица измерения, признак складского учёта, активность и фотографии.

## Вариант товара

SKU, размер, цвет, материал, толщина, количество ножек, модель стула, дополнительные атрибуты, закупочная цена, цена продажи, вес, объём и активность.

## Правила

- SKU уникален.
- Использованный товар не удаляется.
- Неактуальный товар архивируется.
- Исторический заказ хранит снимок названия, характеристик и цены.
- Изменение каталога не изменяет старые заказы.
- Услуги не должны создавать складские остатки.
