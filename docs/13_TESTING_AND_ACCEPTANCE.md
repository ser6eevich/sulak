# Тестирование и критерии приёмки

## После каждого этапа

- успешная сборка;
- линтер;
- строгая типизация;
- применение миграций;
- unit-тесты;
- интеграционные тесты;
- ручная проверка основных экранов.

## Критические сценарии

### Полный заказ
Создание → резерв → рейс → загрузка → перемещение в машину → доставка → оплата → завершение.

### Недостаток
Заказ → частичный резерв → производство → складской приход → полная комплектация.

### Отмена
Резервированный заказ → отмена с причиной → снятие резерва → аудит.

### Возврат
Загруженный заказ → отказ → возвратная зона → осмотр → доступный остаток или брак.

### Конкурентный резерв
Два пользователя одновременно резервируют последний товар. Успешна только одна операция.

### Повторный запрос
Повтор загрузки или платежа не создаёт второе движение или платёж.

### Права
Менеджер не меняет склад; водитель не видит чужой рейс; склад не видит закрытые финансы; неактивный пользователь не входит.

## Готовность модуля

Функции работают, права проверены, миграции применяются, тесты проходят, документация обновлена, известных критических ошибок нет.
