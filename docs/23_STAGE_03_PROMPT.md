# Этап 3 — заказы

Реализуй orders и order_items, генерацию номера, создание и редактирование заказа, выбор клиента, позиции, снимки данных товара, расчёт стоимости, раздельные статусы, список, фильтры, карточку с вкладками, аудит и отмену с причиной.

Менеджер должен работать в рамках прав. Деньги хранить безопасно. Складскую вкладку пока можно показать без фиктивных операций.
