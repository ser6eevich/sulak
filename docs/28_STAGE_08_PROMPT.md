# Этап 8 — финансы

Реализуй платежи, предоплаты, доплаты, оплату при доставке, возвраты, задолженность, вкладку заказа, отчёт водителя, отчёт менеджера и корректирующие записи.

Платёж не удаляется физически. Повторный запрос не создаёт дубль. Статус оплаты рассчитывается. Все действия аудируются.
