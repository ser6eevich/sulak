# Этап 1 — основа проекта

Изучи `/docs` и реализуй только основу.

Сделай Next.js + TypeScript, PostgreSQL/Supabase, миграции, авторизацию, profiles, роли, серверную защиту, RLS, адаптивный layout, страницу входа, меню по ролям, аудит и тестовые локальные учётные записи.

Роли: admin, owner, manager, production, warehouse, logistician, driver.

Проверь вход, блокировку неактивного профиля, прямой доступ к маршрутам, меню каждой роли и аудит изменения роли.

Не реализуй каталог, клиентов, заказы и склад.
